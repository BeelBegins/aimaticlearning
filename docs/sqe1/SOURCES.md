## Sample questions (style only — do not import)

https://sqe.sra.org.uk/assessments/sqe1-assessments/sqe1-sample-questions

Official bank: 110 sample items per FLK (45 original + 65 pre-tested), English
and Welsh, PDF and online. That page still describes 180-question papers; from
January 2027 the live papers are 170. Use the samples for **stem/option style**,
not for count or session grouping.
